TPOD
====

Repository voor oude (werk)documenten betreffende het Toepassings Profiel Omgevings
Documenten (TPOD). De actuele versies van de TPOD documenten zijn te vinden op
[https://www.geonovum.nl/omgevingswet/STOPTPOD](https://www.geonovum.nl/omgevingswet/STOPTPOD)

## github pages

STOPTPOD (geonovum website) verwijst naar github pages, *github.io*, voor:
* IMOW schema (CIMOW, tevens [register](https://register.geostandaarden.nl/xmlschema/tpod/v3.1.2/))
* Symbolenbibliotheek (visualisatie)
* service-producten
  * BOPA_gml
  * CIMOW
  * validatiematrix
* notities
